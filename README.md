# 평일 모닝 주식 브리핑

매주 월~금 07:50(KST)에 그날 새벽 마감한 미국 마지막 거래일의 주도주 기반 테마 TOP 3와 전일 국내 거래대금 TOP 10을 계산해 텔레그램으로 발송합니다.

장중에는 09:00~10:00 및 13:30~15:00(KST)에 KOSPI·KOSDAQ을 각각 감시합니다. 거래대금 TOP 10 순위가 바뀌면 즉시 변동 알림을 보내고, 1·2순위 종목 또는 주도 테마가 의미 있게 바뀔 때도 별도 알림을 보냅니다.

## 이번 운영본의 핵심 규칙

- 국내 기준일은 단순 전일이 아니라 KRX 직전 영업일입니다.
- 미국 테마는 `theme_map.json`의 사전 정의 유니버스 안에서 평가합니다. 미국 전체 시장의 모든 종목을 자동 분류하는 방식은 아닙니다.
- 미국 최신 완료 거래일의 종목만 남긴 뒤 당일 상승률, 절대 거래대금, 20일 평균 대비 거래대금으로 주도주를 먼저 선별합니다. 이후 주도주가 집중된 테마를 상승 확산도와 거래대금 가중 등락률로 재평가합니다.
- 07:50 결과는 미국 마감을 이용한 당일 한국장 가설이며, 아직 개장 전이므로 국내 당일 수급 확정값이 아닙니다. 국내 당일 흐름은 09:00 이후 장중 감시에서 판단합니다.
- 국내 순위는 KOSPI+KOSDAQ을 합산한 뒤 KOSPI 시가총액 1~3위와 ETF·ETN·스팩·레버리지·인버스·우선주를 제외합니다.
- 미국 테마 연계주와 국내 TOP 10의 중복은 종목명이 아닌 6자리 종목코드로 판정합니다.
- `🔥 [신규 N일차]`는 21일 전 KRX 종목목록에 없던 종목의 실제 거래일을 세어 첫 3거래일에만 표시합니다. 과거 종목목록이나 가격 이력을 조회하지 못하면 브리핑을 중단하지 않고 신규 태그만 생략합니다.
- 텔레그램 메시지는 4,096자 제한을 피하도록 3개 메시지로 나누며, 429·5xx 응답은 재시도합니다. HTML 굵은 글씨, 순위 아이콘, 상승·하락 색상 아이콘과 문단 간격을 사용해 모바일 가독성을 높입니다.
- 미국 주도주는 한글 종목명과 티커를 함께 표시합니다. 표시되는 모든 국내 종목은 종목명을 누르면 토스증권의 해당 종목 주문 화면으로 이동하도록 링크를 붙입니다. 휴대전화의 앱 연결 설정에 따라 토스 앱 또는 웹페이지가 열릴 수 있습니다.

## 장중 감시 판단 순서

1. KIS 거래금액 순위, 등락률 순위, 체결강도 순위의 교집합으로 후보를 좁힙니다.
2. 후보의 현재가·거래대금·체결강도·외국인·기관·프로그램 수급과 거래정지/종목상태를 확인합니다.
3. 수급과 유동성을 가장 크게 반영하고, 가격 모멘텀과 과열 여부를 반영해 점수를 계산합니다.
4. 테마는 정적 매핑을 우선하고, 미등록 종목은 KRX 업종으로 보완합니다.
5. 뉴스는 알림 발생 시 보조 설명으로만 붙습니다. 뉴스 제목만으로 순위나 매수 판단을 올리지 않습니다.
   당일 DART 공시도 보조 설명으로 표시하며 점수를 직접 올리지 않습니다.
6. 의미 있는 주도 테마 변화는 첫 30초 스캔에서 즉시 알리고 쿨다운을 적용하지 않습니다. 같은 테마가 유지되는 동안에는 중복 발송하지 않으며, 종목 순위 변화는 기본 3회(약 90초) 이어져야 확정합니다. 1순위 교체 외 종목 순위 알림에는 기본 15분 쿨다운을 적용합니다.
7. KOSPI·KOSDAQ 거래대금 TOP 10은 30초마다 직전 결과와 비교합니다. 첫 조회는 기준선만 저장하고, 이후 순위 상승·하락·신규진입·TOP 10 이탈이 발생한 스캔마다 변동 종목을 한 메시지로 묶어 즉시 보냅니다. 이 알림에는 90초 확정이나 15분 쿨다운을 적용하지 않습니다.

거래대금 순위 표시는 `🔺 10 → 9`, `🔺🔺🔺 10 → 7`, `🔻 4 → 6`, `🆕 신규진입 → 10위` 형식이며 국내 종목명에는 토스증권 링크가 붙습니다. 장 초반처럼 순위가 자주 뒤바뀌는 구간에는 알림 건수가 많을 수 있습니다.

`매수` 표시는 점수 70 이상, 거래대금 12위 이내, 상승률 +1.5~+12%, 체결강도 105 이상, 외국인·기관·프로그램 중 하나 이상의 순매수, 정상 거래상태를 모두 충족할 때만 표시합니다. 나머지는 `관망`입니다. 주문 기능은 없습니다.

현재가·거래금액·체결강도는 기본 30초 간격으로 다시 조회합니다. 외국인·기관 수급은 거래소 확정 틱 데이터가 아니라 KIS 장중 집계값이며 제공 시점 자체가 제한되므로 10분 캐시를 사용합니다. 따라서 이 시스템의 `실시간`은 **수십 초 단위 시장 스캔**을 뜻하며 외국인·기관 수급까지 틱 단위라는 뜻은 아닙니다.

## GitHub 배포

1. 이 폴더의 내용 전체를 GitHub 저장소 최상단에 올립니다.
2. 텔레그램에서 `@BotFather`를 열고 `/newbot`으로 봇을 만든 뒤 발급된 토큰을 복사합니다.
3. 만든 봇과 대화를 열어 `/start` 또는 아무 메시지나 한 번 보냅니다.
4. 브라우저에서 `https://api.telegram.org/bot<봇토큰>/getUpdates`를 열고 결과의 `message.chat.id` 값을 확인합니다. 그룹으로 받을 때는 봇을 그룹에 추가한 뒤 그룹에서 메시지를 보내고 같은 방법으로 음수 형태의 `chat.id`를 확인합니다.
5. GitHub 저장소의 **Settings → Secrets and variables → Actions → New repository secret**에 아래 값을 각각 저장합니다.
   - `TELEGRAM_BOT_TOKEN`: BotFather가 발급한 토큰
   - `TELEGRAM_CHAT_ID`: 메시지를 받을 개인 또는 그룹의 `chat.id`
   - `KIS_APP_KEY`: 한국투자증권 Open API 앱키
   - `KIS_APP_SECRET`: 한국투자증권 Open API 앱시크릿
   - `KRX_ID`: KRX 정보데이터시스템 로그인 ID(07:50 국내 전일자료 조회용)
   - `KRX_PW`: KRX 정보데이터시스템 로그인 비밀번호
   - `NAVER_CLIENT_ID`: 네이버 검색 API Client ID(선택)
   - `NAVER_CLIENT_SECRET`: 네이버 검색 API Client Secret(선택)
   - `DART_API_KEY`: OpenDART 인증키(선택, 당일 공시 보조 표시)
6. **Actions → Weekday Morning Stock Briefing**과 **Intraday KOSPI KOSDAQ Monitor**를 각각 한 번 수동 시험합니다.

스케줄은 `50 22 * * 0-4`(UTC)이며 한국시간으로 월~금 07:50입니다. GitHub Actions 예약 작업은 서비스 부하에 따라 몇 분 지연될 수 있습니다.

장중 감시기는 오전 09:00~10:00와 오후 13:30~15:00에 각각 독립 실행됩니다. 오전·오후 사이의 움직임은 오후 13:30 기준으로 새 기준선을 잡으므로 알림하지 않습니다. 평일 하루 약 150분, 월 21~22거래일 기준 약 3,150~3,300분을 사용합니다. **공개 저장소의 표준 GitHub-hosted runner는 무료로 사용할 수 있지만, 비공개 GitHub Free 저장소의 월 2,000분에는 들어가지 않습니다.** 앱키·시크릿은 코드에 적지 말고 반드시 GitHub Secrets에만 저장해야 합니다.

## 로컬 시험

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
$env:DRY_RUN="true"
python main.py
```

실제 텔레그램 발송 시험:

```powershell
$env:DRY_RUN="false"
$env:TELEGRAM_BOT_TOKEN="123456789:AA..."
$env:TELEGRAM_CHAT_ID="123456789"
python main.py
```

## 관리할 파일

- `theme_map.json`: 미국 테마 구성 종목과 국내 연계주를 수정하는 파일입니다.
- `main.py`: 수집·필터·점수화·메시지·전송 로직입니다.
- `.github/workflows/morning-brief.yml`: 실행 시간과 GitHub Actions 환경입니다.
- `intraday_monitor.py`: 장중 후보 점수화·변화 확정·텔레그램 메시지 로직입니다.
- `kis_client.py`: 주문 기능이 없는 KIS 시세 조회 전용 모듈입니다.
- `.github/workflows/intraday-monitor.yml`: 오전·오후 장중 감시 실행 환경입니다.

테마와 국내 연계주는 시장 상황과 기업 사업 변화에 맞춰 정기적으로 검토해야 합니다. 이 브리핑은 거래대금 기반 정보 요약이며 매수·매도 신호가 아닙니다.
